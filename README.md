One word, the first that comes to mind: **psithurism** — the sound of wind moving through trees. A word almost nobody would guess, vivid enough to hear as you read it, and witty in its own sound: the whispered "psith-" is the rustle it names.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the single word to `/output/entry.txt` and prints exactly that word to stdout. No network, no randomness — every run writes the same bytes.
